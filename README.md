## Project objective
This educational project demonstrates a supervised machine-learning classification workflow using the Breast Cancer Wisconsin Diagnostic dataset available through Scikit-learn. It compares Logistic Regression and Random Forest and provides a Streamlit interface for exploring model predictions.

**Important:** This is an academic demonstration, not a medical device or diagnostic service. Never use its output for medical decisions.

## Setup (Windows / macOS / Linux)
1. Install Python 3.10 or later.
2. Extract the project ZIP.
3. Open a terminal in the project folder.
4. Create and activate a virtual environment (recommended):
   - Windows: `python -m venv .venv` then `.venv\Scripts\activate`
   - macOS/Linux: `python3 -m venv .venv` then `source .venv/bin/activate`
5. Install dependencies: `pip install -r requirements.txt`
6. Train and evaluate the models: `python train_model.py`
7. Launch the app: `streamlit run app.py`
8. Open the local URL printed by Streamlit (usually `http://localhost:8501`).

## Dataset
The project uses the Wisconsin Diagnostic Breast Cancer dataset distributed with `sklearn.datasets.load_breast_cancer`. It contains 569 observations, 30 numerical input features and two target classes. `train_model.py` exports a local CSV copy into `dataset/`.

## Methodology
- Stratified 80/20 train-test split with a fixed random seed.
- Logistic Regression in a pipeline with StandardScaler.
- Random Forest with 300 trees and balanced class weights.
- Compare accuracy, precision, recall and F1-score on the held-out test set.
- Select the model with the higher test-set F1-score and save it with joblib.
